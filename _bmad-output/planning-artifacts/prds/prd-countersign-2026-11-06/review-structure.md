# Structure Review: PRD Countersign

**Content:** `prd.md` (9,042 words, measured with `word_metrics.py`)
**Reader type:** humans. **Style guide:** Microsoft Writing Style Guide, except British spelling and no serial comma (house choices, not flagged).
**My reading of its purpose:** this document exists so that Countersign's engineers and the Orvex reviewers can build and judge the library against testable requirements written in one fixed vocabulary.
**Structure model:** Strategic/Context (Pyramid), the model for PRDs. The vision comes first, then users and journeys, the glossary, features with FRs, NFRs, scope, metrics, and open questions and assumptions. Features and the glossary also follow the Reference/Database model internally (random access, consistent schema), and I judge them against that model where it applies.

**Overall:** the shape is sound. The vision is front-loaded, every FR uses the same schema (statement, "Realizes UJ-n", testable consequences, notes) and traceability runs both ways. Most findings fall into three groups: (1) feature intros and the glossary repeat requirements that the FRs state again; (2) terminology drifts from §3 despite the "no synonyms" rule; (3) a few terms the document leans on are never defined or located (the decision table, the spike, the withdrawal target, task grant).

Content was not challenged. IDs, tags and struck-through §9 questions are left as they are.

## Summary

- **Recommendations:** 23 in total. By main action: CONDENSE 8, QUESTION 5, ADD 3, MOVE 3, CUT 2, PRESERVE 2. Several rows also carry a second disposition (for example CONDENSE + QUESTION).
- **Estimated reduction if every non-QUESTION row is accepted:** about 470 words cut and about 165 added, a net of about **305 words (≈3.4% of 9,042)**. If the NFR-5 "Why" column also moves to the architecture: about **655 words (≈7.2%)**.
- **Length target:** none was given.
- **Trade-offs for comprehension:** condensing the F1/F3/F5 intros keeps a 1–2 sentence overview on purpose, so readers still get the orientation. The additions (glossary groups, missing terms, §0 related artefacts) slightly lengthen the document, but they remove guesswork about load-bearing terms. Moving NFR-5's "Why" column would leave reviewers without the reasoning in the PRD itself.
