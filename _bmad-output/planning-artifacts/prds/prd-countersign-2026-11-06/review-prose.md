# Prose review: PRD Countersign

**Read:** this document exists to help the engineers who will design and build Countersign, and the Orvex reviewers, know exactly what the library must do, as testable pass/fail requirements.

**Style and voice to preserve:** plain, short declarative sentences; contractions ("can't", "doesn't"); British spelling and no serial comma (house choices); named actors in examples (Erin, Sam, Danny, Skander); inline tags (`[OPEN]`, `[tentative]` and so on) followed by a short fragment ("`[OPEN]` Its value."); the repeated motto "A fast refusal is acceptable; a wrong allow is not."; glossary terms used verbatim; struck-through answered questions in §9. None of the rows below changes a requirement, number, tag, ID or decision. Rows phrased "Consider: …?" touch wording close to content, so the author should confirm the meaning.

Structure pass: already applied; no structural rows are repeated here.
